## 三、边界说明

- 本机无 Docker（P0 已记录），迁移验证使用本机原生 PostgreSQL 17.6，不声称 `docker compose up -d` 已实测。
- CI 当前只运行 fmt / clippy / test，**不执行数据库迁移**；P1-1/P1-2 依赖本地实测证据，迁移的自动化校验随 TD-006（`.sqlx/`）与数据库 CI 一并偿还。
- `ecom_p1_verify`、`ecom_p1_identity` 均为一次性验证库，不构成部署产物。
- `user` 是 PostgreSQL 保留字，本项目所有涉及该表的 SQL 统一写作 `"user"`；`NULLS NOT DISTINCT` 依赖 PG15+，本项目基线为 PG17。
